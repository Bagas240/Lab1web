### 1. Struktur Dasar HTML 
![image alt](https://github.com/Bagas240/Lab1web/blob/main/images/Screenshot%202026-10-08%20114052.png?raw=true)

Penjelasan: Bagian ini merupakan kerangka utama dokumen HTML. DOCTYPE menyatakan bahwa dokumen menggunakan HTML5. Tag html membungkus seluruh halaman. Head berisi metadata, charset mengatur encoding karakter, viewport membantu tampilan menyesuaikan perangkat, sedangkan title menentukan judul pada tab browser. Body menjadi tempat seluruh konten yang terlihat oleh pengguna.

### 2. Heading, Paragraf, Formatting, dan Rumus
![image alt](https://github.com/Bagas240/Lab1web/blob/main/images/Screenshot%202026-10-08%20114749.png?raw=true)

Penjelasan: Heading digunakan untuk membentuk hierarki judul. Tag p membuat paragraf. B menampilkan teks tebal, i menampilkan teks miring, dan strong memberi penekanan penting. Sub digunakan untuk tulisan di bawah garis teks seperti angka pada H2O, sedangkan sup digunakan untuk tulisan di atas garis teks seperti pangkat x2.

### 3. Gambar dan Navigasi
![image alt](https://github.com/Bagas240/Lab1web/blob/main/images/Screenshot%202026-10-08%20114826.png?raw=true)

Penjelasan: Tag img digunakan untuk menampilkan gambar. Atribut src menentukan lokasi file, width mengatur lebar, alt menyediakan teks alternatif, dan title memberi informasi tambahan. Tag nav menandai area navigasi. Tag a membuat hyperlink, sedangkan href menentukan tujuan link. Link dapat menuju file lokal maupun website eksternal.

### 4. aftar Keahlian dan Urutan Belajar
![image alt](https://github.com/Bagas240/Lab1web/blob/main/images/Screenshot%202026-10-08%20114856.png?raw=true)

Penjelasan: UL atau unordered list digunakan untuk daftar tanpa nomor, sedangkan OL atau ordered list digunakan untuk daftar yang memiliki urutan. Setiap item daftar ditulis menggunakan LI.

### 5. Halaman Profil Mahasiswa
![image alt](https://github.com/Bagas240/Lab1web/blob/main/images/Screenshot%202026-10-08%20115416.png?raw=true)

Penjelasan: Halaman kedua menggunakan struktur HTML yang sama. Nav digunakan untuk kembali ke beranda atau membuka halaman kedua. HR membuat garis pemisah. Setelah itu ditampilkan judul profil, foto, dan data diri menggunakan heading serta paragraf.

### 6. Keahlian dan Target Belajar 
![image alt](https://github.com/Bagas240/Lab1web/blob/main/images/Screenshot%202026-10-08%20114943.png?raw=true)

Penjelasan: Bagian ini melanjutkan halaman profil dengan daftar keahlian dan target belajar. Setelah seluruh isi selesai, body dan html ditutup menggunakan tag penutup. Dengan demikian struktur dokumen menjadi lengkap.
